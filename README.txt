WEBSITE INFORMASI PENGIRIMAN ANTERAJA BOJONEGORO

Isi:
- 1 halaman utama
- 28 halaman kecamatan
- assets/style.css
- sitemap.xml
- robots.txt
- vercel.json

Cara deploy:
1. Ekstrak ZIP.
2. Masuk ke https://vercel.com/ lalu login.
3. Pilih Add New > Project, lalu import folder/repository website ini.
   Alternatif: gunakan Vercel CLI untuk deploy folder statis.
4. Setelah deploy, gunakan domain Vercel yang diberikan.
5. Ganti URL kanonis di semua HTML, sitemap.xml, dan robots.txt jika domain final berbeda.
6. Daftarkan sitemap.xml di Google Search Console.
